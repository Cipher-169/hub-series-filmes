## ✨ Sobre o projeto

O **Hub de Filmes & Séries** é um projeto pessoal para reunir, em um só lugar, tudo o que assisti, estou assistindo ou quero assistir.

Ele usa o **Trakt** como fonte de informações, mas a organização da biblioteca, o acompanhamento de progresso e o sistema de notas foram pensados de acordo com as minhas preferências.

## 🍿 Funcionalidades

**Biblioteca e acompanhamento**
- Listas de filmes e séries
- Organização por status: planejado, assistindo, concluído, pausado e abandonado
- Busca e visualização de informações dos títulos
- Registro do progresso de séries, com marcação individual de episódios

**Avaliações pessoais**
- Notas de 0 a 100 para filmes
- Notas individuais para cada temporada
- Nota geral independente para cada série
- Edição de avaliações e comentários pessoais

**Histórico e estatísticas**
- Histórico de filmes e séries assistidos
- Estatísticas pessoais, rankings e listas personalizadas

## ⭐ Um sistema de notas próprio

As notas vão de **0 a 100**, o que permite uma avaliação mais detalhada. Nas séries existem duas avaliações independentes:

- **Nota da temporada:** minha avaliação daquela temporada específica.
- **Nota geral da série:** minha avaliação da série como um todo, definida separadamente e **não** calculada pela média das temporadas.

Não há avaliação por episódio. Ao concluir uma temporada, o Hub oferece a opção de avaliá-la, sem tornar isso obrigatório.

## 🧩 Tecnologias

- **HTML, CSS e JavaScript** (sem frameworks)
- **Trakt API** para as informações do catálogo
- **Firebase** para autenticação e armazenamento dos dados pessoais
- **Cloudflare Workers** para operações que não devem ficar expostas no navegador
- **GitHub Pages** para a publicação

A interface segue a mesma identidade visual do meu Hub de Animes: tema escuro, fundo azul-marinho e destaques em coral e dourado.
