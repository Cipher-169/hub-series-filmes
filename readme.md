## ✨ Sobre o projeto

O **Hub de Filmes & Séries** é um projeto pessoal criado para reunir, em um só lugar, tudo o que assisti, estou assistindo ou quero assistir.

A proposta é oferecer uma experiência de organização mais flexível e uma interface própria, indo além de simplesmente registrar títulos: quero construir um espaço para acompanhar meu progresso, guardar minhas impressões e montar minhas próprias avaliações.

O projeto utiliza o **Trakt** como fonte de informações e integração, mas a experiência, a organização da biblioteca e o sistema de notas são pensados para funcionar de acordo com as minhas preferências.

## 🎯 Objetivos

- Organizar filmes e séries em uma biblioteca pessoal.
- Acompanhar o que estou assistindo e meu progresso.
- Registrar filmes concluídos e séries acompanhadas.
- Marcar episódios individualmente.
- Avaliar conteúdos com notas de **0 a 100**.
- Criar rankings, estatísticas e um histórico pessoal.
- Ter uma interface agradável, intuitiva e adaptada a diferentes telas.

## ⭐ Um sistema de notas próprio

Um dos principais objetivos do Hub é ter um sistema de avaliação mais próximo da forma como gosto de avaliar obras.

As notas serão de **0 a 100**, permitindo uma avaliação mais detalhada.

No caso das séries, existirão duas avaliações independentes:

- **Nota da temporada:** representa minha avaliação daquela temporada específica.
- **Nota geral da série:** representa minha avaliação da série como um todo.

A nota geral não será calculada automaticamente pela média das temporadas. Ela será definida separadamente.

Também não será necessário avaliar episódios individualmente. Ao concluir uma temporada, o Hub poderá oferecer a opção de avaliá-la, sem tornar isso obrigatório.

## 🧩 Tecnologias

O projeto utiliza ou prevê utilizar:

- **HTML5** — estrutura das páginas.
- **CSS3** — estilos, identidade visual e responsividade.
- **JavaScript** — funcionalidades e interações.
- **Trakt API** — informações e integração com o catálogo.
- **Firebase** — autenticação e armazenamento dos dados pessoais, conforme a arquitetura definida.
- **Cloudflare Workers** — suporte a operações de integração que não devem ficar expostas no navegador.

## 🎨 Identidade visual

A interface segue como referência visual o meu Hub de Animes, mantendo uma identidade consistente entre os projetos.

A proposta visual inclui:

- Tema escuro.
- Fundo azul-marinho profundo.
- Destaques em coral e dourado.
- Cards com pôsteres e imagens.
- Painéis discretos, bordas suaves e gradientes.
- Navegação simples e responsiva.

O objetivo é manter o foco nos filmes, nas séries e na biblioteca, evitando a aparência de um painel administrativo genérico.
